Developer photo
===============

You do not need to put your photo here when using the database-backed admin content editor.

1. Open /admin
2. Go to Content
3. Upload your JPG, PNG, or WebP photo (max 2MB)
4. Save & publish

The public About page will use the uploaded photo automatically.

If you want a local fallback image before a database is configured, replace the default
static/icons/icon-512.png reference in the frontend with your own image.
