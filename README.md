# L3o Study

A from-scratch AI study workspace built for Render + Mistral + Supabase/PostgreSQL.

## Included
- Cosmic/midnight responsive UI with animated 3D-style hero scene
- Flashcards, Quiz, Exam, Tutor, Summary and 7-day Study Plan modes
- Mistral Chat Completions integration with JSON mode for structured study sets
- KaTeX + Markdown rendering in the browser
- Text/Markdown/CSV/JSON upload into the study workspace
- Admin login with session cookie
- Analytics dashboard with line/doughnut charts
- Editable public-site content (About, story, developer details, privacy, terms)
- Developer photo upload
- PostgreSQL/Supabase persistence
- Render Blueprint (`render.yaml`)
- Health endpoint at `/api/health`

## AI model choice
The default is `mistral-small-latest`, a fast/cost-effective general model. You can switch `MISTRAL_MODEL` to `mistral-medium-latest` for higher-end workloads without changing application code.

## Local run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app:app --host 0.0.0.0 --port 8000
```
Open `http://127.0.0.1:8000`.

## Render
Push this folder's contents to the root of your existing `COOLEO1/Studybuddy` repository. Render can use the included Blueprint. Set `MISTRAL_API_KEY`, `DATABASE_URL`, `ADMIN_USERNAME`, and `ADMIN_PASSWORD` as secrets. `SESSION_SECRET` is generated by the Blueprint.

For Supabase, use the connection string from the project's **Connect** dialog. For an IPv4-only application path, Supabase documents the shared pooler/session connection as an option.

## Important
Do not commit `.env` or API keys. Use Render environment variables for secrets.
